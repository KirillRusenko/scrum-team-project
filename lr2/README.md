# Модель Джелинского-Моранды

Учебный проект (лабораторная работа №2, «Проектирование информационных систем»):
расчёт общего числа ошибок в ПО, времени до следующей ошибки и времени до окончания
тестирования. Задание — `docs/Лабораторная работа №2.pdf`.

## Структура

```
jelinski_moranda/
  data.py       входные данные (вариант 1, таблица 1)
  solver.py     численное решение уравнения для B
  model.py      расчёт K, X(n+1), t_k
  cli.py        ввод данных и вывод результатов
tests/          тесты (pytest)
main.py         точка входа
```

## Запуск

```bash
cd lr2 && python main.py
pip install -r requirements-dev.txt && pytest lr2 && ruff check .   # из корня репозитория
docker build -t jm . && docker run -it jm   # Dockerfile общий, в корне
```
